# Installation sûre — v1.2.0

1. Déploie ce dossier complet sur le domaine Vercel existant.
2. Vérifie `/health` et `/coexistence-check.json`.
3. Les manifests restent `/fr/manifest.json`, `/global/manifest.json`, `/us/manifest.json`.
4. Importe ensuite `imports/nuvio-collections-fr-global-us-all.json`.

Les IDs de Collections existantes sont conservés. Aucun nettoyage/suppression automatique de tes Collections n'est effectué.
