# Nuvio VOD Mondiale

Addon indépendant destiné à coexister avec les éditions France et USA.

- Parent : `🌍 VOD Mondiale`
- Films uniquement
- Périodes : Aujourd’hui, Demain, Hier, Semaine passée, La semaine suivante
- Mois pré-câblés : 2025 → année courante + 4 ans
- Source : TMDb release dates, type `4` (Digital)
- Règle mondiale : seule la **première date Digital connue tous pays confondus** est retenue.
- Aucun filtre achat/location ou watch provider.
