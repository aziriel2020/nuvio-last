# Nuvio Calendar Türkiye v1.4.0

Marché forcé **TR**, langue TMDb **tr-TR**, fuseau **Europe/Istanbul**.

Collections :
Netflix, Prime Video, Disney+, Max, Apple TV+, MUBI, Exxen, GAİN, tabii, TOD, puhutv, TV+, Tivibu, D-Smart GO, S Sport Plus, Türkiye Takvim et VOD Türkiye.

Chaque plateforme contient `Séries` puis `Films` (VOD = Films uniquement).
Chaque dossier commence par :
1. Aujourd’hui
2. Demain
3. Hier
4. Semaine passée
5. La semaine suivante

Puis les mois en ordre décroissant de **Décembre 2030 à Janvier 2015**.

`Türkiye Takvim` agrège les fournisseurs de streaming détectés par TMDb sur le marché TR.
Les services non exposés par TMDb/JustWatch peuvent légitimement retourner un catalogue vide : le dossier reste valide et ne fait pas planter Nuvio.
